# 💻 Vishal Shrestha | Personal Portfolio

Welcome to the repository of my personal portfolio website. This is a highly polished, responsive, and interactive single-page website built to showcase my academic journey, technical skills, coding projects, and design capabilities.

🌐 **Live Demo:** [https://VishalShrestha-V.github.io/portfolio/](https://VishalShrestha-V.github.io/portfolio/)

---

## ✨ Features & Highlights

- **Sleek Dark Theme:** Built with a modern dark mode aesthetic featuring glow effects, HSL customized colors, and ambient background blur.
- **Dynamic Hero Section:** Showcases a morphing shape profile photo wrapper with custom-animated floating technology badges (**Python**, **Canva**, **C++**).
- **Responsive Layout:** CSS Flexbox & Grid architectures optimized for Desktop, Tablet, and Mobile viewport sizes.
- **Scroll Animations:** Intersection Observer API automatically handles smooth fade-in-up animations when elements enter the screen.
- **Skill Indicators:** Visual progress bars that animate dynamically on scroll to represent proficiency levels.
- **Education Timeline:** Clean visual tracking of academic qualifications.
- **Interactive Contact:** Form with real-time CSS transition feedback and active social links.

## 🚀 Running Locally

To run the project on your machine:

1. Clone or download this repository.
2. Direct launch:
   - Double-click **`index.html`** to open it instantly in any modern browser.
3. Via local development server (recommended for changes):
   ```bash
   # Using Python
   python -m http.server 8000
   ```
   *Then visit [http://localhost:8000](http://localhost:8000) in your web browser.*
